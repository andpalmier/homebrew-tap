# homebrew-tap

Homebrew tap for [@andpalmier](https://github.com/andpalmier)'s command line tools.

## Install

```bash
brew install --cask andpalmier/tap/<tool>
```

For example:

```bash
brew install --cask andpalmier/tap/repopsy
```

| Tool | Description |
| --- | --- |
| [apkingo](https://github.com/andpalmier/apkingo) | Extract information from APK files |
| [mbzr](https://github.com/andpalmier/mbzr) | Search MalwareBazaar and submit samples |
| [repopsy](https://github.com/andpalmier/repopsy) | Forensic analysis of git repository history |
| [tfox](https://github.com/andpalmier/tfox) | Search the ThreatFox IOC database |
| [urlhs](https://github.com/andpalmier/urlhs) | Search URLhaus and submit URLs |
| [yrfy](https://github.com/andpalmier/yrfy) | Interact with the YARAify API |

## Casks, not formulae

Every tool here ships as a **cask**. Homebrew expects a formula to build from
source and reserves casks for pre-compiled binaries, which is what these
releases are, so GoReleaser generates casks and its formula support is
deprecated.

Homebrew casks are macOS only. On Linux, install with `go install`, or use the
binaries and container images published on each tool's releases page.

Every file under `Casks/` is generated by GoReleaser on release. Edit the
`homebrew_casks` section of the tool's own `.goreleaser.yaml` instead; changes
made here are overwritten by the next release.
